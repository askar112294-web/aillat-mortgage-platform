# Ailat Mortgage — загрузка фото ЖК

Пакет содержит только изменения для загрузки обложки ЖК из админ-панели.

Скопируйте папки `app` и `components` поверх текущего проекта.

Будут добавлены/заменены:

- `app/api/uploads/projects/route.ts` — новый API загрузки
- `components/admin-panel.tsx` — готовая версия админ-панели с upload
- `components/admin-project-upload.module.css` — стили upload UI

## После копирования

1. В корне проекта выполните:

```bash
npm run build
```

2. Если сборка успешна:

```bash
npm run dev
```

3. Откройте:

`http://localhost:3000/admin`

4. Раздел **Жилые комплексы** → **Загрузить фото** → выбрать JPG/PNG/WebP до 5 МБ.

5. После успешной загрузки нажмите **Сохранить** в верхней части админ-панели.

Файл автоматически создастся в `public/uploads/projects/`.
Папку вручную создавать не нужно.

Важно: это локальное/MVP-хранилище. Для production позже нужно заменить файловое хранение на S3/Supabase Storage, сохранив `coverImageUrl`.
