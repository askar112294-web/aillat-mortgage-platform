# Ailat Mortgage — Data Model v1.1

## 1. Mortgage Product
Единый набор условий, которым управляет продуктовый администратор.

Ключевые параметры:
- minPropertyPrice / maxPropertyPrice — диапазон стоимости недвижимости для калькулятора;
- minFinancingAmount / maxFinancingAmount — реальные продуктовые лимиты суммы финансирования;
- minDownPaymentPercent — минимальный ПВ;
- terms — допустимые сроки;
- annualMarginPercent — временная расчетная наценка для MVP;
- applicationCta — текст основной кнопки.

## 2. Partner (Developer)
Партнер-застройщик. Один партнер может иметь несколько ЖК.

Поддерживаются: название, город, описание, сайт, логотип, контактные данные и статус публикации.

## 3. Property Project (Residential Complex)
Жилой комплекс, принадлежащий одному партнеру.

Поддерживаются: город/район/адрес, диапазон цен и площадей, срок сдачи, координаты, обложка, галерея, ссылка, публикация.

## 4. Application
Лид клиента, созданный из калькулятора или карточки ЖК.

Сохраняются: ИИН, телефон, источник, выбранный ЖК, стоимость недвижимости, ПВ и его %, сумма финансирования, срок, расчет платежа, согласие ПД, статус, ответственный и комментарий менеджера.

## Связи
Partner 1 -> N PropertyProject
PropertyProject 0..1 -> N Application
MortgageProduct 1 -> N Application (условия фиксируются в расчетных полях заявки)
